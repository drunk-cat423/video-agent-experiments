请求格式与图片顺序

使用 Bearer 密钥鉴权，multipart/form-data 上传。重复使用两个 image 字段：先人物关键帧，再商品图。不传蒙版；由 FormData 自动生成 Content-Type 与 boundary。

model    = gpt-image-2
prompt   = 将第一张图片中人物手中的物品自然地替换成第二张的主体物品
image    = 人物关键帧文件
image    = 商品参考图文件
size     = 864x1536
quality  = medium
n        = 1

WawAPI 两个模型与 AnyAIGC Sunburst-c 测试传入 n=1；AnyAIGC GPT Image 2 测试未传 n，默认单张。

可复用的 Node.js 调用示例

需要 Node.js 20 或更新版本。通过环境变量传密钥；将调用放在服务端或桌面应用主进程。每次执行会提交一次付费请求。

费用计算与验证边界

AnyAIGC GPT Image 2 两次分别返回文字输入 24、图片输入 1870、输出 1105 tokens。按核对时 Codex-Gpt-2 分组每百万 token 的 $0.3912、$0.6260、$2.3470 测算，单张 $0.00377344，两张 $0.00754688。Sunburst-c 按 Gpt-Image-2 分组每次 $0.0196 计，两张 $0.0392。以上并非实扣账单。

WawAPI 普通分组四次实扣共 $0.16，Adobe 分组两次共 $0.12。平台将这些结果标为“2K”，页面展示的是实际文件像素。耗时为本地请求到保存图片的约数；旧 AnyAIGC 记录未统计的耗时不补估。

这些是单次样本，不代表长期稳定性或质量排名。模型名和分组按请求与平台记录展示，不用于独立证明上游身份；传入 medium 也不等于已验证上游执行了该档位。遇到超时先核对记录，避免重复提交计费。
